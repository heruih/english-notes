## 怎么用

**没有安装、没有构建、没有依赖。** 双击 `src/英语学习笔记.html`，或用手机浏览器打开。

线上那份是 `gh-pages` 分支的 `index.html`，内容与 `src/` 同文件。

## 关键约定

1. **数据只在浏览器本地**（主键 `english-notes-app-v1`）。不许动已有结构，新功能一律用独立 key。
2. **不重构，只重组**：将来要拆模块时，源码切 `src/js/*.js` + `build.py`，数据模型与交互不变。
3. **交付物是单文件，源码不是**：拆完后只改 `src/js/`，`dist/` 由构建生成。
4. **备份是唯一保证**：标亮 / 设置 / 截图不在"同步码"里，只有「完整备份」能完整带走。
