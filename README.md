# 英语学习笔记（english-notes）

单文件移动端 Web App：看电影/短视频截图学英语，把生词、例句、复习串成闭环。

- 线上：https://english-expression-notes-a-19394.earlymorel20.chatgpt.site
- 使用者：目前只有作者本人（1 人）
- 状态：**在用**。新增功能已冻结，等自用满 30 天再决定加什么。

## 怎么用

这个项目**没有构建步骤**：直接双击 `src/英语学习笔记.html`，或用浏览器打开。

线上版本是同一个文件部署上去的。

## 关键约定

1. **数据只在浏览器本地**（localStorage key `english-notes-app-v1`）。谁都不许动已有数据的结构，新功能一律用独立 key。
2. **不重构，只重组**：以后要拆模块时，源码切成 `src/js/*.js`，由 `build.py` 拼回单文件；数据模型和交互不变。
3. **交付物是单文件，源码不是**：以后拆完模块，改代码只改 `src/js/`，`dist/` 由构建生成。
