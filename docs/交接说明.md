## 一、一句话

我在维护一个**自用的英语学习单文件 Web App**（`英语学习笔记.html`，约 648 KB / 7,970 行），现在交给你接手。

## 二、它是什么

手机浏览器打开即用的工具，闭环是：**看视频截图 → 记进笔记 → 圈出单词 → AI 补例句 → 间隔复习 → 跟读**。

- 无后端、无账号、无构建、无依赖
- 数据全在 localStorage
- 只服务我一个人

## 三、文件在哪

| 文件 | 作用 |
|---|---|
| `src/英语学习笔记.html` | **唯一源码**（改这个） |

| `HANDOFF.md` | 交接单：现状、已知问题、下一步 |

| `docs/数据模型.md` | 数据结构与兼容铁律（改字段前必读） |
| `docs/决策.md` | 为什么这样做 + **已否决方案清单**（别再提） |
| `TESTING.md` | 怎么算通过 |

## 五、你的规矩（重要）

1. **先读** `AGENTS.md` → `HANDOFF.md` → `DEVLOG.md` → `git log -5`，然后**复述你打算改哪个文件**，再动手。
2. **只改 `src/英语学习笔记.html`**，一次只改一个任务涉及的地方。
3. **不改数据**：storage key 名、`words` 字段名一律不动；新功能用独立 key。
4. **说完"完成"必须带三块**：做了什么 / 怎么验的 / 下一步。没验就说没验。
5. 改完 `git commit`，提交前缀用 `[dsh]` / `[codex]` / `[user]`，并在 `DEVLOG.md` 追一行。
